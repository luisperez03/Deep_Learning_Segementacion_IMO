# Fuentes del libro

Desde esta carpeta, instala las dependencias con `python -m pip install -r requirements-libro.txt` y compila con `jupyter-book build libro -W --all`. Abre `libro/_build/html/index.html` para consultar la copia generada.

La configuración, el índice, los capítulos y los fragmentos se encuentran en [libro/](libro/).
